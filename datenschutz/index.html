2. Die App: Keine Kontoerstellung erforderlich

Schlaukorb erfordert keine Registrierung oder Kontoerstellung. Die App kann vollständig anonym genutzt werden.

3. Datenerfassung in der App

Schlaukorb erhebt keine personenbezogenen Daten. Wir speichern keine Namen, E-Mail-Adressen, Standortdaten oder andere persönliche Informationen auf unseren Servern.

4. Lokal gespeicherte Daten

Die folgenden Daten werden ausschließlich lokal auf Ihrem Gerät gespeichert und niemals an uns übertragen:

  • Einkaufsliste
  • Favoriten
  • App-Einstellungen (z. B. Bundesland, Dark Mode)

5. Produktdaten

Die in der App angezeigten Produktdaten (Preise, Angebote) werden von unserer API geladen. Diese Anfragen enthalten keine personenbezogenen Daten.

Wir verwenden keine Werbenetzwerke, keine Analyse-Tools (z. B. Google Analytics, Firebase) und keine Tracking-Dienste – weder in der App noch auf dieser Website.
